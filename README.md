# myhouse-web · 星光宅邸

上海星光引力数字科技有限公司与 Abby 的个人品牌官网。

> 一座由艺术、科技、作品、荣誉与生活记忆组成的可探索宅邸。

## 当前状态

项目处于设计定稿与工程准备阶段，网页尚未开始搭建。

- 空间总结构已确认：房间内部保持真实客人视角，悬浮横切面只用于总览与转场。
- 首发采用非写实 3D 插画视觉与轻量 2.5D 网页交互。
- 快速认识与沉浸参观共用同一套内容。
- 计划支持中文、英文、西班牙语、法语、意大利语、日语和韩语。

## 首发空间

- 门外与玄关：个人身份与快速认识
- 客厅：公司、业务、待客与联系
- 艺术工作间：艺术、插画、品牌与商业创意
- AI 工作室：AI 产品、软硬件与产品出海
- 荣誉室：精选荣誉与电子证书画框
- 阳台：城市、生活、收藏与联系方式

图书馆、完整收藏抽屉、开放式 AI Abby 和少量实时 3D 将在基础体验稳定后扩展。

## 公开仓库提醒

这个仓库对互联网公开。只允许提交网站代码、审核后的公开文案和处理过的网页素材。

不要提交：

- API 密钥、令牌或真实 `.env` 文件
- 原始作品集、PPT、Keynote、PSD、AI、HEIC 或压缩包
- 证书高清原件、合同、报价、客户机密或未公开项目
- 手机号、住址、私人聊天记录或未经同意的他人照片

原始材料请放入本地的 `materials-private/`。该目录内容默认不会进入 GitHub；处理并确认公开后，再将网页版本放入未来的 `public/media/`。

## 技术与发布

技术脚手架将在实施计划确认后建立。拟采用 Next.js、TypeScript、数据驱动内容、响应式 2.5D 场景和 GitHub → Vercel 的预览／发布流程。

本地运行命令、预览地址与正式域名将在工程初始化后补充。

## English summary

**The House of Starlight** is an immersive personal and company website for Abby and her company, 上海星光引力数字科技有限公司. Visitors may either learn the essential information quickly or explore a warm, surreal home built from art, technology, projects, honors, collections, and personal memories.
