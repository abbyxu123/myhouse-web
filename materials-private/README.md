# 本地私人素材区

把尚未审核、体积较大或不适合公开的原始材料放在这个目录中，例如：

- 原始照片与 HEIC
- 证书高清扫描
- PPT、Keynote、PDF 与作品集源文件
- PSD、AI、视频母版与压缩包
- 客户资料、未公开项目与待核实文字

除本说明文件外，`materials-private/` 中的内容已被 `.gitignore` 排除，不会正常进入 GitHub。

建议本地分为：

```text
materials-private/
  profile/
  projects/
  honors/
  collections/
  brands/
  contact/
  translations/
```

素材经过事实、隐私和授权审核，并生成压缩网页版本后，再放入未来的 `public/media/`。不要直接把整个私人素材目录解除忽略或强制提交。
