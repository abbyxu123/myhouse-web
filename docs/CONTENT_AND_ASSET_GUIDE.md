# 内容与素材规范

这份规范保证官网框架搭好以后，可以持续添加项目、荣誉、收藏和多语言内容，而不必重新修改空间结构。

## 1. 公开内容流程

1. 原始材料进入本地 `materials-private/`，不进入 GitHub。
2. 核实事实、版权、隐私和是否允许公开。
3. 建立结构化内容记录。
4. 生成去除元数据、裁切、压缩后的网页衍生图。
5. 将内容标记为 `verified` 与 `approvedForPublic: true`。
6. 只有通过以上步骤的资料才能进入 `public/media/` 和正式页面。

公开仓库中的任何历史内容都应视为可能被永久下载或转存；审核必须发生在提交之前。

## 2. 所有内容共有字段

后续内容文件使用稳定、与语言无关的 ID：

```text
id
slug
status: draft | verified | published
approvedForPublic: true | false
featured: true | false
sortOrder
sourceVersion
lastReviewedAt
```

`approvedForPublic` 默认为 `false`。资料不完整时允许保留占位记录，但不得用推测内容补齐。

## 3. 个人与公司资料

至少记录：

```text
公开姓名
证书／法定姓名及二者公开关系
公开职业身份
公司中文全称
公司正式英文名称
一句价值主张
所在城市的准确含义
邮箱
可公开社交链接或二维码
最后核实日期
```

城市只表示本人可公开表达的生活、学习或工作联系，不得自动写成公司办公室或全球分部。

## 4. 项目记录

每个项目必须提供：

```text
项目名称
年份或时间范围
客户／合作方
项目背景
Abby 的角色 role
具体负责内容 contribution
可核实成果 outcome
关联荣誉
封面图与画廊
项目链接
是否已经公开
Logo／项目素材展示许可
```

角色和工作内容必须具体，例如“创意总监、产品策略、交互设计、插画创作”，不要只写宽泛的“参与项目”。

## 5. 荣誉记录

每项荣誉至少包含：

```text
官方奖项名称
主办方
年份
类别／组别
获奖结果或入围阶段
关联项目
证书网页预览图
核实来源
是否允许公开证书图像
```

证书上传前检查证书编号、条码、二维码、签名和私人信息。网站优先展示裁切与压缩后的预览版，高清原件保存在私人素材区。

## 6. 收藏与彩蛋记录

每件收藏品包含：

```text
名称
所在房间
真实照片
一至两句保留它的原因
关联的记忆、性格、城市或项目
热点提示语
是否允许公开
是否属于彩蛋
```

收藏品只用于增强人物立体感，不承担履历、业务和联系方式等必要信息。

## 7. 合作品牌与 Logo

- 品牌在旧作品集中出现，不等于自动获得官网公开许可。
- 只上传实际需要展示的 Logo 文件，不上传完整品牌素材包。
- 记录合作项目、公开状态、商标权利人和展示许可状态。
- 不暗示品牌背书、持续合作或超出事实的关系。

## 8. 七语内容

支持：`zh`、`en`、`es`、`fr`、`it`、`ja`、`ko`。

- 实体 ID、年份、关系和媒体只维护一次。
- 中文保存唯一事实底稿。
- 英文按国际读者语境改写，不逐字翻译。
- 西班牙语、法语、意大利语、日语、韩语同时对照中英文事实。
- 专有名词进入统一术语表，不在不同页面自行翻译。
- 每条译文记录 `sourceVersion` 与 `translationStatus`。
- 中文事实修改后，与旧版本不一致的译文必须标记为待复核。
- 西、法、意界面为较长文本预留约 30% 空间；日、韩单独检查换行与敬语。

## 9. 文件命名

公开网页素材使用小写英文、数字和短横线：

```text
abby-portrait-formal.webp
project-noonnoon-hero.webp
honor-nvidia-dgx-spark-2026.webp
collection-london-postcard.webp
room-living-background-1920.avif
transition-living-to-art-studio.webm
```

不要在网页素材文件名中使用“最终版”“最新”“改过了”等无法追踪的描述。

## 10. 计划中的公开媒体目录

```text
public/media/
  profile/
  rooms/
  projects/
  honors/
  collections/
  brands/
  contact/
  transitions/
```

当前的高清名片只作为设计参考，不应直接加载到网页首屏。后续生成压缩网页版本后再引用。

## 11. 网页媒体规格

- 房间母图保存在私人素材区；网页输出 960、1440、1920、必要时 2560 像素宽的响应式版本。
- 单房间主视觉目标约不超过 600 KB。
- 项目普通画廊图目标约不超过 250 KB；缩略图约不超过 120 KB。
- 证书预览目标约不超过 300 KB；点击大图目标约不超过 800 KB。
- 透明物件图层目标约不超过 300 KB。
- 短转场视频目标约不超过 800 KB，并提供静态降级图。
- 照片和渲染图优先 AVIF / WebP；PNG 只用于透明图、二维码或确有无损需求的素材。
- 图像导出前删除 EXIF、GPS、设备和拍摄时间等不必要元数据。
- 每张内容图记录替代文字、焦点位置、版权／来源与公开状态。

数值是性能目标，不是牺牲画质的绝对上限；超过目标的文件必须说明原因并经过检查。

## 12. 提交前素材检查

- [ ] 内容已经公开或得到展示许可
- [ ] 人名、客户、年份、角色与成果已经核实
- [ ] `approvedForPublic` 为 `true`
- [ ] 不含手机号、地址、证书编号、未公开二维码或其他敏感信息
- [ ] 其他出镜者已经同意或完成裁切／模糊
- [ ] 已移除 EXIF 与 GPS 元数据
- [ ] 已输出网页尺寸和格式，没有直接使用原始母版
- [ ] 已填写替代文字、来源与权利信息
- [ ] 客户 Logo 与第三方素材的展示范围准确
